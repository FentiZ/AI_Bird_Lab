# AI Bird Lab — проста версія

Максимально простий Python-проєкт, який розпізнає птахів на фотографіях за допомогою моделі Hugging Face.

## Що вміє
- Завантажує JPG, JPEG, PNG (одну або багато фотографій за раз).
- Показує **топ-3** видів і відсоток упевненості.
- Показує довідкові дані українською для 15 поширених видів із `birds.json`.
- Зберігає фото та історію у **SQLite** (`birds.db`).
- Шукає види за назвою, переглядає та видаляє записи.
- Експортує дані у **bird_analysis.csv**.
- Рахує загальну кількість фото, частоти видів і максимум/мінімум упевненості.

Аудіо, порівняння моделей, регіони та інші **необов'язкові** функції свідомо прибрані для простоти.

## Встановлення (Windows / PowerShell)

**Найпростіше на Windows:** двічі клацніть `start.bat`. Він створить середовище, встановить залежності й відкриє застосунок.

Або виконайте команди вручну:

Потрібен Python **3.11 або 3.12** і підключення до інтернету для першого завантаження моделі.

```powershell
cd AI_Bird_Lab_Simple
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Якщо `python` не працює, спробуйте `python3` або перевірте встановлення Python.

Вебінтерфейс відкриється на **http://localhost:8501**. Оберіть один або кілька JPG/PNG і натисніть **«Розпізнати»**.

**Вперше модель завантажує файли з Hugging Face (сотні МБ)**, надалі використовує локальний кеш. На CPU аналіз може бути повільнішим.

## 15 різних фотографій

Можна вибрати **15 власних фотографій різних видів** одразу в інтерфейсі. Не обов'язково вводити всі по черзі.

За бажанням спробуйте завантажити демонстраційний набір із Wikipedia:

```powershell
.\.venv\Scripts\python.exe download_15.py
```

Фото будуть у `samples/`, список URL/атрибуцій — у `samples/sources.csv`. Через доступність серверів і обмеження API частина фото може не завантажитися: повідомлення в консолі покаже, скільки фото реально отримано. Джерела та ліцензії потрібно перевіряти перед публікацією зображень.

## Обрана модель

**[dima806/bird_species_image_detection](https://huggingface.co/dima806/bird_species_image_detection)**
- Тип: ViT, `image-classification` через `transformers.pipeline`.
- Вхід: одне зображення (PIL Image).
- Вихід: список класів `label` та `score`; показуються топ-3.
- Бібліотеки: `transformers`, `torch`, `Pillow`.

Відсоток упевненості **не є перевіреною точністю** моделі. Вид може бути відсутнім у наборі класів; слабке освітлення, фон, ракурс і якість фото можуть погіршувати результат. У довіднику є лише 15 записів; для інших видів програма чесно показує «даних немає». Джерело довідкових відомостей — посилання на сторінку відповідного виду в Wikipedia.

## Тестування

Програмні перевірки SQLite, CSV, парсингу файлів та логіки доступні в `test_simple.py` — їх можна запустити без завантаження ваг моделі командою `python -m unittest test_simple.py` (після встановлення залежностей). Реальне розпізнавання потрібно перевірити на своєму комп'ютері з доступом до Hugging Face.
